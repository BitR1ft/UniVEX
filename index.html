Feature Matrix

Built for Professional Pentesters

Every feature designed around real-world offensive security workflows — from solo researchers to enterprise red teams.

🤖
Multi-Agent LangGraph System
13 specialised AI agents coordinated by a LangGraph StateGraph. ReAct reasoning, human-in-the-loop approval gates, and ML-based intent classification.
LangGraph ReAct GPT-4 Claude-3

MCP Tool Servers

Quick Install

Up and Running in 5 Minutes

Docker-native deployment with a single verified installer. Supports Docker and Podman.

1
Download & verify the installer
Always verify the SHA-256 checksum before executing any remote script.
2
Run the TUI installer
Interactive 10-step whiptail TUI. Generates .env, configures TLS, and starts all services.
3
Open the web interface
Navigate to http://localhost:3000. First-run credentials are printed by the installer.
4
Start your first scan
Enter a target IP or domain in the chat. UniVex handles the rest autonomously.
bash — Docker (recommended)
# Download and verify curl -LO https://github.com/BitR1ft/UniVex/releases/latest/download/install.sh curl -LO https://github.com/BitR1ft/UniVex/releases/latest/download/install.sh.sha256 sha256sum -c install.sh.sha256 bash install.sh
bash — Podman / rootless
# Rootless container support curl -LO https://github.com/BitR1ft/UniVex/releases/latest/download/install-podman.sh curl -LO https://github.com/BitR1ft/UniVex/releases/latest/download/install-podman.sh.sha256 sha256sum -c install-podman.sh.sha256 bash install-podman.sh
bash — From source (dev)
git clone https://github.com/BitR1ft/UniVex.git && cd UniVex cp .env.example .env # edit with your API keys docker compose up --build

FAQ

Frequently Asked Questions

Everything you need to know about UniVex before you get started.

UniVex is a fully-autonomous, AI-powered penetration testing platform. It uses 13 specialised AI agents built on LangGraph to automate the entire offensive security kill chain — reconnaissance, vulnerability discovery, exploitation, post-exploitation, and compliance reporting — with support for 90+ security tools and 12+ LLM providers.
Yes. UniVex is fully open-source and released under the MIT License — free to download, use, and modify. You only need your own API keys for the LLM providers you choose to use. Self-hosted vLLM is supported for fully air-gapped or cost-free deployments.
UniVex supports 12+ LLM providers: OpenAI (GPT-4o, GPT-4), Anthropic (Claude 3), Groq, OpenRouter, AWS Bedrock, DeepSeek, Qwen, GLM, Kimi, and vLLM for self-hosted/air-gapped deployments. You can configure a different model per agent via YAML.
UniVex integrates with 90+ security tools including Nmap, Naabu, Nuclei, FFuf, SQLMap, Metasploit, WPScan, Subfinder, Amass, Katana, Wayback Machine, MassDNS, and many more — all wrapped as MCP (Model Context Protocol) servers so agents can call them natively.
Run curl -LO https://github.com/BitR1ft/UniVex/releases/latest/download/install.sh && bash install.sh. Docker or Podman is required. A full TUI installer guides you through environment setup. You're up and running in under 5 minutes.
UniVex automatically maps every finding to OWASP Top 10, PCI-DSS 4.0 (12 requirements), NIST 800-53 (20 control families), and CIS Controls v8 (18 controls). It generates audit-ready evidence packages and compliance reports in PDF, HTML, and Markdown formats.
UniVex is designed exclusively for authorised security testing. You must have explicit written permission from the system owner before running any tests. Unauthorised use against systems you do not own or have permission to test is illegal and unethical. Always follow your jurisdiction's computer misuse laws.
